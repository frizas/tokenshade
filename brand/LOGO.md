# TokenShade logo

The primary mark is a friendly sun wearing shades: one ink color on full
transparency, with no baked background.

- `assets/tokenshade-generated-mark.png` is the approved image-generated mark,
  extracted to true alpha and normalized to one visible RGB color.
- `assets/logo.svg` is the clean scalable companion.
- `assets/icon.*` is the small-icon export.
- `assets/logo-dark.*` and `assets/logo-light.*` are transparent wordmark
  lockups for light and dark surfaces.

The site palette uses only ink, coral, and cream. The logo file itself remains
background-free.

Do not add gradients, shadows, tools, arrows, token symbols, currency, or
OpenAI marks to the logo.
